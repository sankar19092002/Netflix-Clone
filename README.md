# Netflix Clone – Responsive Landing Page

## 📌 Project Overview
Netflix Clone is a frontend web development project inspired by the Netflix landing page. It provides a user interface similar to Netflix, featuring a navigation header, language selection, sign-in button, membership section, and trending movies section.

The project is developed using HTML and CSS to create an attractive and user-friendly interface.

## 🚀 Features
- Netflix-inspired landing page design.
- Netflix logo in the navigation header.
- Language selection dropdown.
- Sign In button.
- Membership registration section with email input.
- Get Started button.
- Trending Now section displaying movie posters.
- Horizontal scrolling for trending movies.
- Dark background with red styling.

## 🛠️ Technologies Used
- **HTML5** – Structure of the web page.
- **CSS3** – Styling, layout, colors, Flexbox, and positioning.

## ⚙️ How to Run the Project

1. Download or clone the project repository.
2. Open the project folder in VS Code.
3. Make sure `index.html` and `netflix.css` are in the same folder.
4. Open `index.html` in a web browser.
5. Explore the Netflix-inspired landing page.

## 💻 Main Sections

1. **Header Section:** Displays the Netflix logo, language dropdown, and Sign In button.
2. **Hero Section:** Displays the main heading, membership information, and email input.
3. **Trending Now Section:** Displays movie posters with numbered rankings and horizontal scrolling.
